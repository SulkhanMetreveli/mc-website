Import from Supabase

One-time copy of every login, client, request, document and DMS record from the old Supabase project into this site's own storage. Run it once; it can be re-run, but that overwrites anything changed here since.

Before you start

  1. In Supabase → SQL Editor, run the short script from supabase/EXPORT_FOR_MIGRATION.sql. It lets the import read existing password hashes so nobody has to change their password.
  2. Copy the project's service_role key (Supabase → Project Settings → API). It is only sent to this site's own functions for the duration of the import and is never stored.
  3. Keep the Supabase project running until the import reports done.
